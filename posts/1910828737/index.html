# 软件推荐：SpleeterGui（人声音乐分离）

# 一、软件介绍

SpleeterGUI 是由法国的音乐流媒体公司 Deezer 推出的一款专业音轨 AI 分离软件，软件功能还是比较强大的，基础的操作方式，能够满足用户的对音轨分离的基本需求。SpleeterGUI 主要功能就是可以将音乐的人声和各种乐器声分离，其基于 TensorFlow 开发，本身运行速度非常快，分离过程可以在 GPU 或 CPU 上执行。在 GPU 上运行，如果它将音频文件分成四个音轨，可以比实时速度快 100 倍。这款软件能够帮助用户将音频进行编辑分离，通过该软件能够向 Spleeter 提供一个音频文件，它就会将其分成两个、四个、五个等多个独立的音轨，其中两条音轨包括人声音乐分离，四条音轨包括人生、鼓点、贝斯、其它分离，五条音轨包括在四条音轨上直接多加了一种钢琴，你可以选择你所需要分离的音轨直接一键操作，最多就只能分离五条音轨，你只需要将音频文件上传至界面，选择你需要分离的音轨模式，就可以将你的音频轨道直接分离，而且还支持 mp3、wav、ogg 等常见音频格式，让我们可以快速进行处理。

# 三、安装使用说明

1、双击 SpleeterGUI 进行安装，可以自定义安装目录，安装好之后，暂时不要运行 SpleeterGUI。

打开 https://github.com/deezer/spleeter/releases，下载 2stems.tar.gz 、 4stems.tar.gz 、 5stems.tar.gz > 并解压

在安装目录新建文件夹命名为 pretrained_models ，将解压后的三个文件夹放入此文件夹里

等复制完成，你现在就可以运行软件了

题外话：
首先需要选择训练模型，其实就是分离方式，这个上面也解释了，一般选择 2 就可以了。
之后设置输出目录，选择需要分离的文件即可。
转换完成之后，会为你保存为 wav 无损格式：

这个软件最大的优点在于什么呢？
不仅可以用来消除音乐的人声，你也可以尝试用来消除影视作品的人声啊～

如果报错
对了，如果你运行 SpleeterGUI 时出现如下报错，是因为你电脑缺少必要的.NET Framework 运行库
用 Aio-Runtimes 安装常用的运行库之后就行了：
