电脑硬件入门指南

电脑里面有什么？
看看它们如何协同工作。

台式计算机由多种彼此协作的部件组成。PC Anatomy 让你在 3D 空间中拆开它们、查看连接关系，并从完整机箱一直深入到 GPU 的单个计算核心。

01 · 机箱

机箱将整机部件固定在一起。框架支撑主板、显卡、硬盘和电源；安装孔位固定组件，通风开口与风扇位则为流经外壳的空气提供路径。在 PC Anatomy 中，可移开玻璃侧板和顶盖，查看 ATX 机箱内部的安装关系。

02 · 主板

主板连接计算机各部件。CPU 插座固定处理器；DIMM 插槽安装内存；PCI Express 插槽连接显卡等扩展卡。供电电路为处理器供电，M.2 插槽连接紧凑型固态硬盘。查看主板，可找到插座、连接器、散热片及其间的小型电子器件。

03 · CPU

中央处理器运行程序指令，包括应用逻辑和操作系统任务。现代台式处理器具有多个核心，并用缓存将常用数据保留在附近。PC Anatomy 展示 Ryzen 9 9950X 和 Core Ultra 9 285K 的小芯片或芯粒组织。硅芯片视图用于说明架构，并非精确晶体管布局。

04 · 显卡

显卡由 GPU、专用显存、供电和散热系统组成。GPU 并行执行大量操作，用于图形及其他任务。打开 RTX 5090 模型，可分离风扇、导风罩、鳍片组、热管和电路板，再进入 GB202 架构，探索图形处理簇与流式多处理器。

GPU 菜单中还提供两款显卡。AMD Radeon RX 9070 XT 可深入至 Navi 48，其着色器引擎、工作组处理器与计算单元组合向量算术、矩阵运算和光线追踪。Intel Arc B580 可深入至 BMG-G21，展示渲染切片、Xe 核心，以及配有 XMX 矩阵引擎的向量引擎。

05 · 内存

随机存取存储器（RAM）保存处理器当前使用的程序与数据。它提供高速工作空间，但断电后内容消失。台式内存插入 CPU 旁带防呆结构的 DIMM 插槽。查看主板，可观察内存模块、插槽和用于对齐的缺口。

06 · 存储

存储设备在关机后仍保存文件。固态硬盘使用闪存保存数据，由控制器管理读写。PC Anatomy 提供数据、电源分离的 SATA SSD，以及“存储”菜单中的 M.2 NVMe SSD。拆开后可查看控制器、NAND 闪存、DRAM、防呆触点和固定螺钉；也能从主板进入。这些设备在用途与连接方式上都不同于 RAM。

07 · 电源

电源将市电转换为计算机使用的直流电，独立电缆分别向主板、CPU 和显卡供电。可在机箱中追踪这些连接，再查看电源模型了解内部转换阶段。

虚拟拆解仅用于教学，不是打开真实电源的操作指南。真实电源内部可能存在危险高压，断电后也不应自行拆开。

08 · 散热

处理器将部分电能转换为热量。导热界面把热量传到散热器，热管和金属鳍片将热量分散到较大表面，风扇再将热空气带走。对比塔式 CPU 散热器、显卡散热、机箱风扇及独立液冷模型，可理解完整传热路径中的各部分。

如何使用

  1. 从完整组装开始。拖动旋转模型，用滚轮或双指捏合缩放。
  2. 逐步拆解。移动底部滑块，从“已组装”经过“分层拆解”到“零件清单”，或点击“自动”。
  3. 深入查看。点击可继续探索的零件进入细节层级，右键查看说明、隐藏、单独显示或聚焦。在触屏上，可使用组件菜单和搜索。
  4. 沿层级移动。通过探索导航和面包屑，在整机、组件及内部结构间切换。

这是一款运行于浏览器、依赖 JavaScript 和 WebGL 的免费开源工具。组件条目附带说明、规格与参考资料。机械模型为教学近似；特定处理器与 GPU 则依据公开架构展开。

让浏览器中的 3D 更流畅

硬件加速允许浏览器使用 GPU 渲染 3D。如果探索不够流畅，请检查是否开启。这是通用建议，并不等于应用已读取到浏览器设置。

  • 桌面 Chrome：打开“设置 → 系统”，启用“使用图形加速功能（如果可用）”，然后重新启动。也可将 chrome://settings/system 粘贴至地址栏。
  • 桌面 Edge：打开“设置 → 系统和性能”，找到并启用“使用图形加速功能（如果可用）”，再重新启动。也可访问 edge://settings/system。
  • 桌面 Firefox：打开“设置 → 常规 → 性能”，取消“使用推荐的性能设置”，显示并启用“使用硬件加速（如果可用）”，再重启。

重启浏览器前，请先保存其他标签页中的工作。Safari 和移动浏览器通常自动管理加速，不提供此开关；受管理的浏览器或不受支持的驱动也可能使该设置不可用。
